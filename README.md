# Aether

Monorepo starter for a Telegram-based VPN service.

## Apps
- `apps/bot` — Telegram bot
- `apps/api` — backend API
- `apps/admin` — admin panel

## Packages
- `packages/db` — Prisma schema and DB client
- `packages/shared` — shared types/constants
- `packages/vpn-core` — VPN provider abstraction
- `packages/payments` — payment integrations

## Quick start
```bash
npm install
```
